# Contributing

Just make a PR (Pull Request) with some changes you made and eventually it will be reviewed!

## PR Naming

For PR Naming it is recommended to name it in the format of : "[TYPE] <change>"

Examples:
- `[BUGFIX] Fixed Player Viewer crashing on mac`
- `[FEATURE] Taunt Key in Milk (Remixed)`
- `[OPTIMIZATION] Custom-made waveform system that uses more than 50mb`

## Types of PRs you should do

It is recommended to do bug fixes or optimizations for PRs cause any bug fix or optimization would be very nice.

For features it's more complicated.

If it's a for-fun feature like adding a random chance for something to happen doing a song or while in a menu,
It might get accepted but if it doesn't fit then it can't be added. 

If it's a debug tool, that's almost always welcome.

If it's a new cutscene, a major gameplay change, etc,
it's probably not going to be added depending on the current vision for the game.

It depends.
